動くQR

QRをパラパラ漫画のように切り替えて、ネットなしで文字やファイルを渡します。

– / – 周回 0

受け取る側は別のスマホで「受け取る」を開き、この画面にカメラを向けます。何周しても大丈夫で、読み逃したコマは次の周で拾います。

「カメラを起動」を押して、動くQRを枠の中に映してください
0 / – 読み取り 0 コマ/秒

緑のマスが受け取れたコマです。全部そろうと自動で中身を表示します。

しくみ

送る中身を圧縮し、数百文字ずつに分けて1枚ずつQRにします。1枚目（コマ0）にはファイル名や大きさの情報が入っています。各コマには「何枚中の何枚目か」が書いてあるので、受け取る側は順番がばらばらでも、読み逃しがあっても、全部そろった時点で元に戻せます。
